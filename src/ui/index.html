Validación de calificación

Emitir autorización firmada para un recurso

El profesor selecciona una clave privada PEM cifrada de forma local. La clave no se almacena en la aplicación ni se distribuye al alumno. Puede emitir permisos de apertura, de portafolio completo, por criterio o por actividad. Son permisos locales disuasorios; no garantizan que el HTML no pueda abrirse fuera de este programa.

Recepción de calificaciones desde aplicaciones originales

Seleccione el CSV de resultados descargado por el alumno. Se aceptan los CSV de portafolio de las UD1, UD2, UD5, UD6 y UD7, y el CSV de examen UD4. El archivo no incorpora una identidad verificable: confirme el estudiante y todas las notas antes de validar.

Bandeja de entregas recibidas

El sistema recopila las notas al finalizar portafolios y exámenes. Los resultados son propuestas sin firma de autoría y no modifican las calificaciones oficiales hasta que el profesor los valide. Los informes de portafolio no sustituyen la revisión de evidencias profesionales.
